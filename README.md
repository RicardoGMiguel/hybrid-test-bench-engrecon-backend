# <mark>[PROJETO]</mark> | Backend

Repositório para código fonte do backend do projeto <mark>[PROJETO]</mark>

Servidor Node.js com Express
Database <mark>[DATABASE]</mark>

<hr>

Passo a passo para execução:

### Após clonar o repositório, acessar diretório e instalar dependências necessárias

```
  yarn
```

Configurar a conexão com o database fornecendo um arquivo `.env`, segundo `.env.example`

### Inicializar o servidor em modo de DESENVOLVIMENTO

```
  yarn dev
```

### Executar build do projeto

```
  yarn build
```

### Executar servidor em modo de PRODUÇÃO

```
  yarn start
```
